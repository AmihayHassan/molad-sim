# Molad Sim

Watch the Moon's phases and the planets' orbits through time, next to the Hebrew calendar.

**Live:** https://amihayhassan.github.io/molad-sim/

A 3D Sun–Earth–Moon simulation in one self-contained HTML file ([index.html](index.html)). Positions come from
[Astronomy Engine](https://github.com/cosinekitty/astronomy) for any date, past or future:

- Moon phase, age and the Hebrew date (switching at sunset), with Rosh Chodesh marked
- Planets, Jupiter's moons, Titan, Pluto, Ceres and the asteroid belt on their real orbits
- Solar and lunar eclipses, seasons and day length for any city
- Time bar with play/reverse, steps, a date editor (BCE dates use the Julian calendar) and "Jump to" events
- NASA imagery with streamed close-up tiles, or geography-based generated textures offline
- English and Hebrew interface

Open `index.html` in a browser; it needs an internet connection for the libraries and imagery.
Image credits are listed in the app's left panel. [Solar System Simulation Requirements.md](Solar%20System%20Simulation%20Requirements.md)
is the original specification.
